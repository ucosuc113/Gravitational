# GRAVITATIONAL

## Gravitational is a puzzle game where you have to connect a point of light to a goal, using the geodesic of spacetime

The game consists of 23 total levels, and fully dynamic music throughout all 23 levels.

how to play: [click in this itch io link](https://ucosuc113.itch.io/gravitational)
